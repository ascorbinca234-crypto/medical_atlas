# Атлас биохимии

Пробная версия содержит ровно два конспекта: классификация аминокислот и моносахариды (глюкоза и фруктоза). Они выделены из существующих материалов автора; источник — `data/demo.json`, оформление — `src/template.html`.

Полная версия содержит 131 вещество, 275 реакций, схемы, анимации и режимы учёбы. Для неё нужна действующая подписка на биохимию; одна регистрация доступ не даёт. Полный шаблон и исходные данные сохранены вне публичного репозитория в `medical_atlas_private/biochem-atlas/base/`, дополнительные данные — в `data/` и `src/locked.js` закрытой папки.

Публичная сборка: `python3 build.py`. Полная: `python3 build.py --full`. Переменная `ATLAS_PRIVATE` меняет расположение закрытой папки. Полный пакет `server/content/biochem.js` исключён из Git. [Развёртывание и права доступа](../DEPLOY.md).

Скелетные формулы рисует SmilesDrawer 1.0.10; локальная копия из опубликованного npm-пакета находится в `vendor/` вместе с MIT-лицензией. Учебные формулы имеют резервное отображение без этой библиотеки.

Медицинское содержание в этой технической доработке не рецензировалось.
