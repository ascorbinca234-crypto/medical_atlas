# Микробиология v7

Атлас обновлён из авторского `atlas-mikrobiologii-v7.html` (SHA256 `63af4ee3853c60eaa4649239c7a87a04d49722cd68a52253323b0641c21b6db9`).

Полный набор: 29 тем, 7 зачётов, 29 обзорных глав, 118 досье, 440 вопросов двух факультетов, 62 схемы, 130 фотографий с исходными подписями и атрибуцией, 38 анимаций и карта 67 антибиотиков из 21 класса.

Без подписки доступны два конспекта — морфология и физиология — с их схемами, фотографиями и анимациями. Остальные материалы выдаёт существующий защищённый API `/content-v3/micro/<пакет>`. Вход сам по себе не открывает материалы. Администратор и подписчик видят полный набор. Состояние подписки, её отзыв и срок действия проверяются прежним общим загрузчиком. Закрытый материал не сохраняется в браузерный кэш.

Публичный каталог содержит только навигационные сведения. Досье загружаются отдельно, обзорные главы — по зачётам, анимации — по выбранному процессу, фотографии и фототренажёр — страницами по 12 снимков. Вопросы обоих факультетов и карта антибиотиков имеют собственные пакеты. Все 191 пакет проверяются по контрольным суммам. Разбиение сохраняет загрузку каждой страницы в пределах серверного ответа; листы тем и обзорные главы не включают весь атлас.

## Импорт и сборка

```sh
python3 micro-atlas/import.py /path/to/atlas-mikrobiologii-v7.html
python3 micro-atlas/build.py --full
```

Оригинальные модули импортируются только в соседнюю закрытую папку `../medical_atlas_private/micro-atlas/v7/`; корень можно переопределить через `ATLAS_PRIVATE`. Публичная сборка `python3 micro-atlas/build.py` воспроизводится без закрытых исходников. Полная сборка проверяет уникальность ID и ссылки тем, зачётов, вопросов, схем и снимков. Отсутствующий или неполный оригинал останавливает сборку.

Обновление сервера: `node server/scripts/package.js` пересобирает все четыре предмета в `server/dist/function.zip`. Сначала развернуть этот архив в существующей функции с сохранением настроек, затем публиковать страницы сайта. Старые архивы микробиологии не используются для новой сборки.

## Прогресс и проверки

Отметки прочитанных тем используют прежние ID и ключ `micro.read`. Новые отметки и ответы тренажёра передаются в общий личный кабинет. Смена темы и открытие досье проходят через проверку доступа. Исходный конфликт CSS у полноэкранного проигрывателя исправлен: стиль кнопки увеличения применяется только к кнопке.

```sh
node --test server/test/*.test.js
node server/test/browser-micro-v7.cjs
```

Браузерная приёмка проверяет все 191 маршрута, обзорные главы, фотографии, анимации, карту, оба набора вопросов, прогресс, отзыв подписки и мобильную пробную версию. Медицинское содержание перенесено из авторского файла без редакторских изменений; технические проверки не являются клинической проверкой.
