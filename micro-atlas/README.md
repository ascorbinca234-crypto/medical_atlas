# Микробиология v8

## Отчёты о прогрессе

В «Подготовка к экзамену → Данные» доступны «Скачать PDF» и «Скачать Word (.docx)». Отчёт включает сводку, уровни тем, задания к повторению, журнал ошибок, свои факты и сравнения, заметки, результаты экзаменов и тестов, последние 50 ответов. Пустые разделы подписаны явно.

Документы создаются в браузере. PDF использует локальные jsPDF и DejaVu Sans из `assets/report-export/`; Word создаётся как настоящий OOXML DOCX. Формирование отчёта не заменяет и не сбрасывает прогресс. Для переноса прогресса остаётся отдельная кнопка «Скачать резервную копию (JSON)».

Экспорт подключён в публичном интерфейсе и совместим с существующим защищённым пакетом `prep`: обновлять серверную функцию для этой возможности не требуется.

Атлас обновлён из авторского `atlas-mikrobiologii-v8.html` (SHA256 `52acf01ab1f24edc6da1d6511202dd5ac6b8fcf6a12f664fde12e002a410963b`).

Полный набор: 29 тем, 7 зачётов, 29 обзорных глав, 118 досье, 440 вопросов двух факультетов, 62 схемы, 130 фотографий с исходными подписями и атрибуцией, 38 анимаций и карта 67 антибиотиков из 21 класса.

Без подписки доступны два конспекта — морфология и физиология — с их схемами, фотографиями и анимациями. Остальные материалы выдаёт существующий защищённый API `/content-v3/micro/<пакет>`. Вход сам по себе не открывает материалы. Администратор и подписчик видят полный набор. Состояние подписки, её отзыв и срок действия проверяются прежним общим загрузчиком. Закрытый материал не сохраняется в браузерный кэш.

Публичный каталог содержит только навигационные сведения. Досье загружаются отдельно, обзорные главы — по зачётам, анимации — по выбранному процессу, фотографии и фототренажёр — страницами по 12 снимков. Вопросы обоих факультетов и карта антибиотиков имеют собственные пакеты. Все 322 пакета проверяются по контрольным суммам. Разбиение сохраняет загрузку каждой страницы в пределах серверного ответа; листы тем и обзорные главы не включают весь атлас.

## Подготовка к экзамену

Версия v8 добавляет план на сегодня, интервальное повторение, журнал ошибок, свои факты, сравнения «Не перепутай», схемы и процессы, смешанные тесты, экзамен и прогресс по темам. Все маршруты `#learn/...`, включая ссылки с параметрами, используют защищённый пакет `prep`. Для построения заданий по всему курсу он содержит тексты тем, обзорных глав, досье, вопросы, этапы анимаций и данные антибиотиков. Обычное чтение по-прежнему загружает отдельную тему.

В `prep` находятся только подписи и метаданные снимков. Каждый видимый снимок загружается отдельным защищённым пакетом `photo-<id>`; ошибки и лимиты загрузки допускают повтор. Крупнейший пакет — около 2,57 МБ до сжатия. Медиа не сохраняются в постоянный кэш браузера. Ключ `micro.study` хранит пользовательские ответы, ошибки, факты и расписание; прежние `micro.srs` и `micro.srsph` переносятся при первом открытии подготовки. Ответы также учитываются в общем журнале личного кабинета. Просмотр обычных тем не запускает неполный реестр и не перезаписывает учебный прогресс.

## Импорт и сборка

```sh
python3 micro-atlas/import.py /path/to/atlas-mikrobiologii-v8.html
python3 micro-atlas/build.py --full
```

Оригинальные модули импортируются только в соседнюю закрытую папку `../medical_atlas_private/micro-atlas/v8/`; корень можно переопределить через `ATLAS_PRIVATE`. Публичная сборка `python3 micro-atlas/build.py` воспроизводится без закрытых исходников. Полная сборка проверяет уникальность ID и ссылки тем, зачётов, вопросов, схем и снимков. Отсутствующий или неполный оригинал останавливает сборку. Для каждого импортированного модуля проверяется SHA256.

Обновление сервера: `node server/scripts/package.js` пересобирает все четыре предмета в `server/dist/function.zip`. Сначала развернуть этот архив в существующей функции с сохранением настроек, затем публиковать страницы сайта. Старые архивы микробиологии не используются для новой сборки.

## Прогресс и проверки

Отметки прочитанных тем используют прежние ID и ключ `micro.read`. Новые отметки и ответы тренажёра передаются в общий личный кабинет. Смена темы и открытие досье проходят через проверку доступа. Исходный конфликт CSS у полноэкранного проигрывателя исправлен: стиль кнопки увеличения применяется только к кнопке.

```sh
node --test server/test/*.test.js
node server/test/browser-micro-v8.cjs
```

Браузерная приёмка проверяет 191 маршрут и разделы подготовки, обзорные главы, фотографии, анимации, карту, оба набора вопросов, прогресс, отзыв подписки и мобильную пробную версию. Медицинское содержание перенесено из авторского файла без редакторских изменений; технические проверки не являются клинической проверкой.
