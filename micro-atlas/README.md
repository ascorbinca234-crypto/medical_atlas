# Микробиология

Раздел сайта `/micro-atlas/`, импортированный из архива автора `micro-atlas-src_2.tar.gz`.
В пробной версии доступны только два базовых конспекта: `g1` — морфология и `g2` — физиология микроорганизмов. В публичных файлах нет текста остальных 20 тем, 103 досье и 205 вопросов. Публичный каталог содержит только названия и короткие описания тем.

## Сборка

Нужны Python 3 и Node.js. Из корня проекта:

```sh
python3 micro-atlas/build.py
```

Эта команда воспроизводит публичный `micro-atlas/index.html` без закрытых исходников. Для проверки полного набора и подготовки серверного пакета:

```sh
python3 micro-atlas/build.py --full
```

Закрытые исходники должны находиться в соседней папке `../medical_atlas_private/micro-atlas/src/`. Другой корень можно передать через `ATLAS_PRIVATE`. Полная сборка требует 22 темы, 6 файлов досье и `questions.js`, проверяет ID и ссылки и прекращает работу при ошибке или отсутствии материалов. `server/content/micro.js` исключён из Git. Перед упаковкой облачной функции необходимо также собрать фармакологию и биохимию, чтобы сохранить все три закрытых пакета.

## Доступ и публикация

Главная страница и кабинет ссылаются на микробиологию. Прочитанные конспекты можно отмечать; кабинет показывает микробиологию и последнюю открытую тему. Поиск, досье, вопросы и тренажёр не раскрывают платные материалы в пробной версии.

Полная микробиология загружается через `/content/micro` после проверки серверного права. Документ хранилища `access:<userId>` содержит `micro: {expiresAt: <Unix milliseconds>, revoked: <boolean>}`. Это отдельный серверный документ, его нельзя изменить через профиль или синхронизацию прогресса. Отсутствующее, просроченное или отозванное право даёт HTTP 403; простой вход не даёт права. Полный материал не сохраняется в IndexedDB или localStorage.

Автоматическая выдача права после оплаты ещё не реализована. Продажи пока отключены; интерфейс это сообщает. На старой облачной функции без `micro.js` остаётся доступна пробная версия. Для полной выдачи требуется обновить облачную функцию с новым обработчиком и закрытым пакетом; отправка в GitHub сама этого не делает. Фармакология и биохимия пока сохраняют прежний режим доступа после регистрации; перевод их на два пробных конспекта и оплаченные права остаётся отдельной задачей.

Нельзя копировать исходный `dist/index.html`, все досье или закрытые темы в публичный Git: ограничение только в интерфейсе не защищает эти материалы. Медицинские сведения импортированы из архива без редакторской проверки; технические тесты не подтверждают их клиническую точность.

## Проверки

```sh
cd server
npm test
```

Тесты проверяют два пробных конспекта, закрытые маршруты, отсутствие закрытых исходников в публичной папке, поведение при отказе и задержке API, серверные права и невозможность открыть микробиологию чужой покупкой или изменением профиля.
