# Атлас фармакологии

Пробная версия: два полных конспекта — общая фармакология (`k-gen`) и афферентная иннервация (`k-aff`). Препараты из этих конспектов остаются доступными в поиске и карточках. Остальные темы представлены заголовками; регистрация сама по себе их не открывает.

Полная версия из предоставленного архива содержит 522 записи единого каталога, 13 конспектов, 16 подробных листов, 273 подробных досье и исходный тренажёр с режимами «Карточки», «Тест», «Дозы и рецепты». Модель «Организм» доступна бесплатно.

Общая страница и инструменты исходного приложения используют единый реестр всего курса. Поэтому готовая полная программа загружается как защищённый пакет `atlas` после проверки доступа к фармакологии. При переходах внутри этой программы сохраняется полный каталог, а не выбранная ранее пробная тема. Проверки входа, подписки, срока, отзыва, лимиты и персональные метки остаются на сервере. Пакеты отдельных лекций сохранены для совместимости. Без права доступа остаются два пробных конспекта, бесплатная модель и исходный тренажёр на пробных материалах. Число 522 на обзорной странице берётся из полной сборки, а не из урезанной базы.

Публичная сборка: `python3 build.py`. Полная: `python3 build.py --full`; закрытые исходники берутся из соседней папки `medical_atlas_private` или `ATLAS_PRIVATE`. Старые публичные данные сохранены в `farma-atlas/base/src/` этой папки. Манифест перечисляет все обязательные файлы. Закрытые материалы собираются в `server/content/topics/farma/`; они исключены из Git.

[Развёртывание и права доступа](../DEPLOY.md). Учебный материал не заменяет учебник; медицинское содержание в этой технической доработке не рецензировалось.

## Бесплатные анимации

Без регистрации доступны два базовых конспекта, модель «Организм» и анимации действия всех 176 препаратов модели. Публичный `src/body.js` создаётся при полной сборке из разрешённых к открытию данных модели; полный текст конспектов, рецепты и подробные досье в него не входят. Ссылки `#body`, `#body/<препарат>` и `#drugs` сохраняют доступ к бесплатным материалам.
