# Атлас фармакологии

Интерактивный атлас по фармакологии для 3 курса лечебного факультета. Один HTML-файл, без сервера и без установки.

## Что внутри

- **Конспекты лекций** (13): схемы, классификации, списки для выписывания и формулировки — так, как спрашивают на зачётах. Сверху у каждой лекции закреплена панель «Раздел / Препараты».
- **Все препараты** (522): у каждого одна карточка — дозировка и форма выпуска, зачем выписывают, побочные эффекты, противопоказания, формулировки из конспекта, действие на организм, механизм по шагам.
- **Организм** (176 препаратов): анимированная схема тела — сердце и ЭКГ, сосуды и АД, зрачок, бронхи, ЖКТ, железы, ЦНС; режимы доз, отравления, антидоты.
- **Учить**: карточки с интервальным повторением, тест в формулировках зачёта, тренажёр доз и рецептов. Прогресс хранится в браузере (localStorage).
- Анимированные блок-схемы: кнопка «▶ Проиграть», наведение подсвечивает цепочку «причина → следствие».
- Горячие клавиши: `/` или `Ctrl+K` — поиск; в «Учить»: пробел — перевернуть карточку, `1` `2` `3` — оценка.

## Как открыть

Скачайте `index.html` и откройте в браузере. Интернет нужен только для шрифтов.

## Опубликовать как сайт (GitHub Pages)

1. Создайте репозиторий и загрузите в него все файлы из этой папки (**Add file → Upload files**).
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
3. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Как править

Исходники лежат в `src/`, а `index.html` собирается из них:

```bash
python3 build.py
```

| Файл | Что в нём |
|---|---|
| `src/k_*.js` | Конспекты лекций (по одному файлу на лекцию) |
| `src/rx_*.js` | Дозы, формы выпуска, показания и побочные эффекты препаратов, которых нет в конспектах |
| `src/drugs.js` | Досье: молекулярный механизм и влияние на системы органов |
| `src/data.js` | Подробные листы (углублённые схемы) |
| `src/body.js` | Модель «Организм» |
| `src/learn.js` | Режим «Учить» |
| `src/fx.js` | Анимации, тема, горячие клавиши |
| `src/app.js` | Отрисовка страниц, единая карточка препарата, поиск |
| `src/style.css` | Стили (светлая и тёмная тема) |

## Важно

Материал для подготовки к занятиям, а не медицинская рекомендация. Дозы с пометкой «не из конспекта» — ориентир для взрослых по инструкциям; сверяйте с инструкцией к препарату и действующими клиническими рекомендациями.
