# Атлас фармакологии

Пробная версия: два полных конспекта — общая фармакология (`k-gen`) и афферентная иннервация (`k-aff`). Препараты из этих конспектов остаются доступными в поиске и карточках. Остальные темы представлены заголовками; регистрация сама по себе их не открывает.

Полная версия содержит 13 конспектов, 16 подробных листов, 273 досье, модель «Организм» и тренажёр. Она загружается после серверной проверки действующей подписки на фармакологию.

Публичная сборка: `python3 build.py`. Полная: `python3 build.py --full`; закрытые исходники берутся из соседней папки `medical_atlas_private` или `ATLAS_PRIVATE`. Старые публичные данные сохранены в `farma-atlas/base/src/` этой папки. Манифест перечисляет все обязательные файлы. Результат полной сборки — `server/content/farma.js`, который исключён из Git.
