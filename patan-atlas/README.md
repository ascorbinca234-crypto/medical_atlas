# Атлас патологической анатомии (`patan-atlas/`)

Общая патанатомия по занятиям кафедры ПСПбГМУ (0–11): 26 тем, 118 микропрепаратов (56 из перечня кафедры + 62 дополнительных), 41 макропрепарат, 31 электронограмма, 184 тестовых вопроса. Один файл `index.html`, без сборки и зависимостей.

## Установка
Положить папку `patan-atlas/` в корень сайта рядом с `pathophys-atlas/`. Ссылки «Все атласы» (`../`) и «Личный кабинет» (`../cabinet/`) уже стоят.

## Интеграция (как у патофизиологии)
- id атласа — `patan`; состояние пользователя — `localStorage['patan-atlas:v1']`.
- `window.MA_TOPICS` = 26 тем `{id, title}`, `demo: ["norma", "necrosis", "infarction"]` (занятия 0–1).
- Подключены `../auth/config.js`, `../auth/auth.js?v=subject-access-v1`, `../progress/progress.js?v=topic-delivery-v1`.
- Прогресс: `MAP.sections('patan', [{id, n, total:1, learned, seen, locked:false}])` и `MAP.card({ok})` за каждый ответ в тесте и диагностикуме.
- Запуск: по умолчанию код атласа (`<script id="patan-app" type="text/plain">`) выполняется напрямую. Когда сервер начнёт отдавать темы для `patan`, нужно поставить `window.PATAN_USE_BOOT = true` — тогда запуск пойдёт через `MA.bootAtlas('patan', 'patan-app')`.
- **Важно:** сейчас данные всех 26 тем лежат в `<script id="patan-data">` (`window.PATAN_DATA = {lessons, topics}`), то есть в таком виде весь атлас открыт. Чтобы закрыть темы на сервере, всё, кроме демо-тем, нужно вынести из `topics` в серверные пакеты тем.

## Маршруты
`#` — обзор, `#diag` — диагностикум (тренажёр и список), `#method` — окраски и алгоритм описания, `#<topicId>` — тема, `#<topicId>/mp-<id>` — конкретный препарат.

## Фото
Микропрепараты: `img/micro/<topicId>--<id>.jpg`, макропрепараты: `img/macro/<topicId>--<id>.jpg`, электронограммы: `img/em/<topicId>--<id>.jpg`. Номера препаратов — по занятиям (например, «3.5», «М 4.2»). Полный список номеров и имён файлов — в `photo-list.md`. Когда файл появляется в папке, атлас сам показывает его на месте заглушки (клик — увеличение). В режиме «Экзамен» при наличии фото описание скрывается.
