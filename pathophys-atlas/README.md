# Атлас патофизиологии

React-атлас из предоставленного `PathoAtlas.jsx`: 28 тем, интерактивные схемы, пошаговый патогенез, порочные круги, ловушки, таблицы и самопроверка. Две открытые темы: «Болезнь и этиология» и «Общий патогенез».

Остальные материалы и их визуализации выдаются по одной теме через `/content-v3/pathophys/:topic`. Применяются существующие проверки подписки, срока, отзыва, персональные метки и общие лимиты загрузки. Старые покупки других предметов патофизиологию не открывают.

## Сборка

В этой папке один раз выполните `npm ci`. Публичная сборка: `python3 build.py` из корня репозитория или `npm run build` здесь. React, иконки и Tailwind включены в HTML; CDN для выполнения приложения не нужен.

Для полной сборки сохраните оригинал в `${ATLAS_PRIVATE}/pathophys-atlas/PathoAtlas.jsx`. По умолчанию закрытая папка — `../medical_atlas_private` относительно репозитория. Затем выполните `python3 build.py --full` из корня. Сборка проверяет совпадение открытых уроков с оригиналом и создаёт 28 самостоятельных пакетов в `server/content/topics/pathophys/`. Пакеты и оригинал в публичный Git не попадают. `node server/scripts/package.js` включает их в архив функции.

`import.mjs` использовался для первоначального переноса: он перезаписывает базовый интерфейс и не нужен при обычной сборке. Дальнейшие изменения интерфейса вносятся в `src/PathoAtlas.jsx`.

Занятия и отметки «Изучено» передаются в общий журнал и отображаются в личном кабинете. Экзаменационный прогон использует открытые уроки и текущую загруженную тему; выбор другой закрытой темы запрашивает её заново.

Тесты: `cd ../server && npm test`. Проверка в браузере: `node test/browser-pathophys.cjs` (установленный Chrome либо `ATLAS_BROWSER=/путь/к/браузеру`).
